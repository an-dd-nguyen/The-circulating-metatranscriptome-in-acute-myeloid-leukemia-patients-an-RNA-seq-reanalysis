# The-circulating-metatranscriptome-in-acute-myeloid-leukemia-patients-an-RNA-seq-reanalysis
KrakenUniq_Report_Generation used to generate KrakenUniq report and filtering contaminant taxa\
BeatAML_Microbial_Landscape used to generate figure of Phyla distribution and PCoA of samples colored by SampleType (AML, Technical Replicate, Healthy)\
BeatAML_Genus_Analysis used to generate figure of top 30 genus in proportion/abundance in AML samples, Group 12 Healthy vs AML most differentiated genus, Gram proportion, BC distance between AML pairs and Healthy-AML pairs\
BeatAML_EdgeR and BeatAML_clusterprofiler used to generate figure of host expression GSEA between low - high metatranscriptome load and comparison of cell type deciphered by CIBERSORTx\
BeatAML_DiversityEdgeR and BeatAML_Diversity_ClusterProfiler used to generate figure of host expression GSEA between low - high/ high - low butyrate producing genera\
BeatAML_Clinical_Statistics used for statistical analysis of microbial genus - patient clinical/drug response information\
ToExecute2 details the actual function used for statistical analysis
